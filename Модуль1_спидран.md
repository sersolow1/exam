# Модуль 1: быстрый маршрут (спидран)

Коротко: **только действия, в оптимальном порядке**. Объяснения, зачем нужна каждая команда, есть в `Модуль1_методичка.md`.

Обозначения:
- ⏳ здесь что-то грузится или перезапускается, **не жди, переключайся** туда, куда указано;
- ✅ быстрая проверка (секунды);
- `ens19/ens20/ens21` — имена интерфейсов со стенда sysahelper. **Сначала проверь свои через `ip a`.**

> ⚠️ Команды вводи руками, с обычными `-` и `'` (на сайте встречаются «длинные тире» и «ёлочки»).
> В EcoRouter работает Tab-дополнение, а `conf t` = `configure terminal`.

### Минимум vim (всё, что понадобится)

| Клавиши | Что делают |
|---|---|
| `vim файл` | открыть файл. Если его нет, файл будет создан при сохранении |
| `i` | режим вставки: печатаешь текст как в блокноте |
| `Esc` | выйти из режима вставки в командный режим |
| `:wq` + Enter | сохранить и выйти (`:wq!` — если файл только для чтения, например `/etc/sudoers`) |
| `:q!` + Enter | выйти **без** сохранения (если накосячил) |
| `/текст` + Enter | найти строку с «текст», `n` — следующее совпадение |
| `G` / `gg` | в конец / в начало файла |
| `o` | новая строка под курсором, сразу в режиме вставки |
| `x` | удалить символ под курсором (например, `#` в начале строки) |
| `dd` | удалить строку |
| `:6` + Enter, затем `dG` | перейти на 6-ю строку и удалить всё от неё до конца файла |

Типовая правка «найди строку X и замени значение»: `/X` → Enter → курсор на строке → `i` → исправить → `Esc` → `:wq`.
Раскомментировать строку: встать на `#` в её начале → `x`.

## Почему порядок именно такой

Самые долгие операции: `apt-get` на ISP (iptables, tzdata), `apt-get install bind` на HQ-SRV и перезагрузка HQ-CLI.
Цепочка зависимостей такая:

```
ISP получил интернет ──► apt на ISP (⏳) ──► iptables NAT на ISP ──┐
                                                                  ├──► HQ-SRV apt bind (⏳) ──► DNS
Теги VLAN в PVE + ВСЯ настройка HQ-RTR (NAT, маршрут, VLAN) ──────┘
```
Поэтому:
1. PVE-теги делаем первыми, это 30 секунд.
2. На ISP запускаем apt как можно раньше и, **пока он качает**, целиком настраиваем оба роутера.
3. HQ-CLI отправляем в перезагрузку и, **пока он грузится**, настраиваем серверы.
4. HQ-SRV запускаем на установку bind и, **пока он качает**, настраиваем BR-SRV.

| # | Где | Что | Параллельно (пока ждёшь) |
|---|---|---|---|
| 1 | PVE | теги VLAN 100/200 | — |
| 2 | ISP | имя, сеть, forwarding, **запуск apt** | ⏳ → шаги 3–4 |
| 3 | HQ-RTR | всё сразу (11 блоков) | ISP качает |
| 4 | BR-RTR | всё сразу | ISP качает |
| 5 | ISP | iptables, timezone | — |
| 6 | HQ-CLI | имя + NM + DHCP + TZ, **reboot** | ⏳ → шаги 7–8 |
| 7 | HQ-SRV | имя, IP, **запуск apt bind**, юзер, ssh, TZ | ⏳ → шаг 8 |
| 8 | BR-SRV | имя, IP, юзер, ssh, TZ | bind качается |
| 9 | HQ-SRV | конфиг BIND, запуск, свой DNS | — |
| 10 | все | финальные проверки + отчёт | — |

## Шаг 1. PVE (веб-интерфейс гипервизора), ~1 мин

1. Узел → System → Network: у `vmbr3` (HQ-SW) должно быть **VLAN aware = Yes**. Если нет: Edit → галочка → OK → **Apply Configuration**.
2. ВМ **HQ-SRV** → Hardware → Network Device (net0) → Edit → **VLAN Tag = 100** → OK.
3. ВМ **HQ-CLI** → Hardware → Network Device → Edit → **VLAN Tag = 200** → OK.
4. HQ-RTR **не трогаем**: без тега его порт на vmbr3 работает как trunk.

Тег применяется на лету, ВМ перезагружать не нужно.

## Шаг 2. ISP, ~2 мин + ⏳ загрузка

**2.1 Имя**
```bash
hostnamectl set-hostname isp; exec bash
vim /etc/sysconfig/network
```
Найди строку `HOSTNAME=` и сделай её такой:
```
HOSTNAME=isp
```

**2.2 ens19 (в интернет) → DHCP**
```bash
vim /etc/net/ifaces/ens19/options
```
Найди строку `BOOTPROTO=` и замени значение:
```
BOOTPROTO=dhcp
```

**2.3 ens20 (к HQ-RTR) и ens21 (к BR-RTR)**
```bash
mkdir /etc/net/ifaces/ens20 /etc/net/ifaces/ens21
vim /etc/net/ifaces/ens20/options
```
Файл пустой (новый), напиши:
```
TYPE=eth
BOOTPROTO=static
```
```bash
cp /etc/net/ifaces/ens20/options /etc/net/ifaces/ens21/options   # у ens21 такой же
vim /etc/net/ifaces/ens20/ipv4address
```
Напиши:
```
172.16.1.1/28
```
```bash
vim /etc/net/ifaces/ens21/ipv4address
```
Напиши:
```
172.16.2.1/28
```

**2.4 Forwarding**
```bash
vim /etc/net/sysctl.conf
```
Найди `/ip_forward`, строку `net.ipv4.ip_forward = 0` замени на:
```
net.ipv4.ip_forward = 1
```

**2.5 Применить и запустить долгое**
```bash
systemctl restart network
ip -br a ; ping -c2 77.88.8.8          # ✅ адреса на трёх интерфейсах + интернет

# ⏳ ЗАПУСКАЕМ ДОЛГОЕ и уходим на роутеры:
apt-get update && apt-get install -y iptables tzdata
```
➡️ **Не жди**, сразу переходи к HQ-RTR.

## Шаг 3. HQ-RTR: всё за один заход, ~5 мин

Логин по умолчанию: `admin` / `admin`.

```
enable
conf t
hostname hq-rtr
ip domain-name au-team.irpo
username net_admin
 password P@ssw0rd
 role admin
 exit
ntp timezone utc+3
!
! --- интерфейсы ---
interface isp
 ip address 172.16.1.2/28
 exit
interface vl100

 exit
interface vl200

 exit
interface vl999
 ip address 192.168.99.1/29
 exit
ip route 0.0.0.0/0 172.16.1.1
!
! --- привязка к портам ---
port te0
 service-instance te0/isp
  encapsulation untagged
  connect ip interface isp
  exit
 exit
port te1
 service-instance te1/vl100
  encapsulation dot1q 100 exact
  rewrite pop 1
  connect ip interface vl100
  exit
 service-instance te1/vl200
  encapsulation dot1q 200 exact
  rewrite pop 1
  connect ip interface vl200
  exit
 service-instance te1/vl999
  encapsulation dot1q 999 exact
  rewrite pop 1
  connect ip interface vl999
  exit
 exit
!
! --- GRE ---
interface tunnel.0
 ip address 10.10.10.1/30
 ip tunnel 172.16.1.2 172.16.2.2 mode gre
 ip ospf authentication message-digest
 ip ospf message-digest-key 1 md5 P@ssw0rd
 exit
!
! --- OSPF ---
router ospf 1
 ospf router-id 10.10.10.1
 passive-interface default
 no passive-interface tunnel.0
 network 10.10.10.0/30 area 0
 network 192.168.100.0/27 area 0
 network 192.168.200.0/24 area 0
 network 192.168.99.0/29 area 0
 exit
!
! --- NAT ---
interface isp
 ip nat outside
 exit
interface vl100
 ip nat inside
 exit
interface vl200
 ip nat inside
 dhcp-server 1
 exit
interface vl999
 ip nat inside
 exit
ip nat pool VLAN100 192.168.100.1-192.168.100.30
ip nat pool VLAN200 192.168.200.1-192.168.200.254
ip nat pool VLAN999 192.168.99.1-192.168.99.6
ip nat source dynamic inside-to-outside pool VLAN100 overload interface isp
ip nat source dynamic inside-to-outside pool VLAN200 overload interface isp
ip nat source dynamic inside-to-outside pool VLAN999 overload interface isp
!
! --- DHCP ---
ip pool VLAN200 192.168.200.2-192.168.200.254
dhcp-server 1
 pool VLAN200 1
  mask 24
  gateway 192.168.200.1
  dns 192.168.100.2
  domain-name au-team.irpo
  exit
 exit
write memory
```
Отступы только для наглядности, вводить их не нужно. Строки с `!` — комментарии, их не вводить.
Если `dhcp-server 1` на vl200 выдаст ошибку, что сервера ещё нет, повтори его **после** блока DHCP:
`interface vl200` → `dhcp-server 1` → `exit` → `write memory`.

✅ `show ip interface brief`: isp, vl100, vl200, vl999, tunnel.0 в статусе **up**. `ping 172.16.1.1` проходит.
(`ping 77.88.8.8` заработает, только когда ISP сделает NAT, т.е. после шага 5.)

**7.3 ⏳ Запускаем долгое в фоне и продолжаем тут же**
```bash
(apt-get update && apt-get install -y bind bind-utils) > /root/apt.log 2>&1 &
```

**7.4 Пользователь**
```bash
useradd sshuser -u 2026
passwd sshuser                          # P@ssw0rd ×2
usermod -aG wheel sshuser
vim /etc/sudoers
```
`G` (в конец) → `o` (новая строка) → напиши:
```
sshuser ALL=(ALL:ALL) NOPASSWD: ALL
```
`Esc` → **`:wq!`** (с `!`, потому что файл только для чтения).

**7.5 SSH**
```bash
vim /etc/openssh/sshd_config
```
Найди каждую строку через `/`, убери `#` в начале (`x`) и поставь значение:

| Ищешь (`/…`) | Было | Должно стать |
|---|---|---|
| `/#Port` | `#Port 22` | `Port 2026` |
| `/MaxAuthTries` | `#MaxAuthTries 6` | `MaxAuthTries 2` |
| `/Banner` | `#Banner none` | `Banner /etc/openssh/banner` |

Строки `AllowUsers` в файле нет. Встань, например, под строку `Port 2026`, нажми `o` и напиши:
```
AllowUsers sshuser
```
`Esc` → `:wq`.
```bash
vim /etc/openssh/banner
```
```
Authorized access only
```
```bash
systemctl restart sshd
```
Если sshd не стартует, значит опечатка в конфиге. Посмотри `sshd -t`, команда покажет строку с ошибкой.

➡️ Переходи на BR-SRV. bind качается в фоне (`tail /root/apt.log`, чтобы посмотреть).

| Серверы не выходят в интернет, роутеры выходят | NAT на RTR: `ip nat inside/outside`, pool |
| Нет OSPF-соседа | разные ключ/пароль MD5, забыт `no passive-interface tunnel.0` |
| HQ-CLI без адреса | `dhcp-server 1` на vl200; NM native; тег 200 |
| bind не стартует | `named-checkconf -z`, `journalctl -u bind`, `//` перед forwarders, права `root:named` |

**Отчёт** (адреса, VLAN, GRE, OSPF, DHCP) удобно заполнять во время ⏳-пауз. Таблицы есть в основной методичке.
